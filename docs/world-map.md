# 월드맵 읽기

왕궁을 선택하면 GitHub에 게시된 릴리스와 버전 태그를 함께 볼 수 있습니다. 릴리스에는 게시 시각과 릴리스·사전 릴리스 배지가, 그 외 태그에는 대상 커밋 시각과 태그 배지가 표시됩니다. 최신 기록 10개부터 보고 더 보기로 펼칠 수 있습니다. 열린 이슈의 상세는 성벽 밖의 몬스터를 선택해 확인합니다. 닫힌 이슈는 연결된 PR 팝업의 이슈 링크로 엽니다. 개발 광장을 선택하면 열린 PR과 시설 이력을 볼 수 있습니다. 광장이 없는 왕국에서는 작업 목록 버튼으로 같은 목록을 엽니다. 각 PR 시설을 선택하면 상세 기록을 볼 수 있습니다. 지도에서 클릭할 수 있는 대상에 마우스를 올리면 실선 외곽선과 옅은 배경색이 나타납니다. 이슈와 PR을 가리키거나 선택하면 연결된 대상은 점선 외곽선과 같은 배경색으로 강조됩니다. 지도 전체를 스크롤해 다른 왕국으로 이동할 수 있습니다.

| 위치           | 지도에서 읽을 수 있는 정보                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 성벽 밖        | 열린 이슈마다 몬스터가 생깁니다. GitHub에서 확인한 상위 이슈는 보스가 되고 하위 이슈가 주변에 모입니다.                  |
| 성벽 안        | 열린 PR마다 시설이 생깁니다. 이슈에 연결되지 않은 PR도 자체 시설을 가집니다. 제목 첫 GitMoji가 시설의 종류를 결정합니다. |
| 왕궁과 광장    | `main`과 `dev`가 모두 있으면 다리와 해자가 왕궁과 개발 광장을 구분합니다. 그 밖에는 저장소의 기본 브랜치가 왕궁입니다.   |
| 성벽 안쪽 상단 | 확인된 누적 수치가 1 이상인 유산만 나타납니다. 건물을 선택하면 수치와 출처를 볼 수 있습니다.                             |

## 작업과 모험가

몬스터 아래에는 이슈 번호와 참여한 Codex·Claude가 표시됩니다. 현재 실행 중인 모험가는 개발이나 리뷰 동작을 하고, 개발이나 리뷰를 마친 모험가는 참여가 확인된 열린 이슈와 PR에 대기 상태로 남습니다. PR 시설에서도 번호 아래에 참여자가 모이며 CI 실행 중에는 GitHub Actions 파티장이 등장하고 CI가 끝나면 그 자리에서 대기합니다. 경고 테두리는 개입이 필요한 작업을, 짧은 반짝임은 최근 상태나 집계의 변화를 나타냅니다.

연결된 PR의 고유 커밋이 늘면 몬스터가 일정 크기까지 자랍니다. 이슈 아래 모험가는 개발 중에 공격 동작을, 리뷰 중에 고개를 숙여 두루마리를 살피는 동작을 합니다. 귀환하면 제자리에서 쉬고, 실패한 모험가는 쓰러진 자세로 표시됩니다. PR 시설 옆 룬은 리뷰의 양을 보여줍니다. 승인과 수정 요청은 서로 다른 봉인으로 표시합니다. 정확한 수치와 기록은 이슈·PR 상세에서 확인할 수 있습니다.

이슈가 닫히면 몬스터가 사라지고, 다시 열리면 부활 효과가 나타납니다. PR은 머지되거나 닫히면 시설 이력으로 이동하고 다시 열면 지도에 돌아옵니다. PR 머지와 이슈 종료는 각각의 GitHub 상태를 따릅니다.

## 브랜치 도로망

도로는 PR의 작업 브랜치와 대상 브랜치를 연결합니다. 다리는 왕궁과 광장의 위치를 구분하는 장식이며, 실제 브랜치 관계는 확인된 PR 기록으로 읽습니다. 지도에는 열린 PR과 연결된 경로를 우선해 최대 여섯 개를 표시합니다. 작은 분기점에서 갈라지는 곡선을 따라 PR 시설과 연결된 이슈를 찾을 수 있습니다. 여러 PR이 여러 이슈와 연결된 경우 기본 지도에서는 순서가 교차하는 이슈 연결을 생략합니다. 이슈나 PR을 가리키거나 선택하면 해당 연결을 확인할 수 있습니다. 분기점을 선택하면 브랜치 이름과 PR을 볼 수 있고, 추가로 확인한 브랜치는 목록에서 볼 수 있습니다.

건물 외형과 네 유산의 집계 대상은 [SVG 도감](assets.md)에서 확인하세요.
