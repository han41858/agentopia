# 월드맵 읽기

왕궁을 선택하면 GitHub에 게시된 릴리스와 버전 태그를 함께 볼 수 있습니다. 릴리스에는 게시 시각과 릴리스·사전 릴리스 배지가, 그 외 태그에는 대상 커밋 시각과 태그 배지가 표시됩니다. 최신 기록 10개부터 보고 더 보기로 펼칠 수 있습니다. 열린 이슈의 상세는 성벽 밖의 몬스터를 선택해 확인합니다. 닫힌 이슈는 연결된 PR 팝업의 이슈 링크로 엽니다. 개발 광장을 선택하면 열린 PR과 작업 이력이 함께 표시되며, 긴 이력은 목록 안에서 스크롤할 수 있습니다. 광장이 없는 왕국에서는 작업 목록 버튼으로 같은 목록을 엽니다. 각 PR 시설을 선택하면 상세 기록을 볼 수 있습니다. 지도에서 클릭할 수 있는 대상에 마우스를 올리면 실선 외곽선과 옅은 배경색이 나타납니다. 이슈와 PR을 가리키거나 선택하면 연결된 대상은 점선 외곽선과 같은 배경색으로 강조됩니다. 지도 전체를 스크롤해 다른 왕국으로 이동할 수 있습니다.

왕궁 팝업 제목의 저장소 주소(`owner/repo`)를 선택하면 해당 GitHub 저장소가 새 탭에서 열립니다.

왕궁 팝업에서 **월드맵에서 제거**를 선택한 뒤 **제거**를 누르면 해당 저장소가 월드맵에서 사라집니다. 확인 팝업에서 **취소**를 누르거나, Escape 키를 누르거나, 팝업 바깥을 클릭하면 저장소를 유지하고 왕궁 팝업으로 돌아갑니다.

| 위치           | 지도에서 읽을 수 있는 정보                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 성벽 밖        | 열린 이슈마다 몬스터가 생깁니다. GitHub에서 확인한 상위 이슈는 보스가 되고 하위 이슈가 주변에 모입니다.                                    |
| 성벽 안        | 열린 PR마다 시설이 생깁니다. 이슈에 연결되지 않은 PR도 자체 시설을 가집니다. 제목 첫 GitMoji가 시설의 종류를 결정합니다.                   |
| 왕궁과 광장    | 왕궁은 존재하는 `main`, `master`, GitHub 기본 브랜치 순으로 선택합니다. 기본 브랜치가 왕궁과 다를 때만 개발 광장과 해자·다리가 나타납니다. |
| 성벽 안쪽 상단 | 확인된 누적 수치가 1 이상인 유산만 나타납니다. 건물을 선택하면 수치와 출처를 볼 수 있습니다.                                               |

## 작업과 모험가

몬스터 아래에는 이슈 번호와 참여한 Codex·Claude가 표시됩니다. 현재 실행 중인 모험가는 개발이나 리뷰 동작을 하고, 개발이나 리뷰를 마친 모험가는 참여가 확인된 열린 이슈와 PR에 대기 상태로 남습니다. PR 시설에서도 번호 아래에 참여자가 모이며 CI 실행 중에는 GitHub Actions 파티장이 등장하고 CI가 끝나면 그 자리에서 대기합니다. 경고 테두리는 개입이 필요한 작업을, 짧은 반짝임은 최근 상태나 집계의 변화를 나타냅니다.

월드 모드와 간단 모드 모두 PR 시설 아래에는 참여 캐릭터가 표시되지만, PR 상세 팝업에는 캐릭터 영역이 없습니다. 팝업에서는 GitHub 활동 기록, 상태, 링크를 확인할 수 있습니다. CI가 실패하면 별도 상단 배지 대신 GitHub Actions 목록의 최신 실행 행에서 실패 상태를 확인할 수 있습니다.

연결된 PR의 고유 커밋이 늘면 몬스터가 일정 크기까지 자랍니다. 이슈 아래 모험가는 개발 중에 공격 동작을, 리뷰 중에 고개를 숙여 두루마리를 살피는 동작을 합니다. 귀환하면 제자리에서 쉬고, 실패한 모험가는 쓰러진 자세로 표시됩니다. PR 시설 옆 룬은 리뷰의 양을 보여줍니다. 승인과 수정 요청은 서로 다른 봉인으로 표시합니다. 정확한 수치와 기록은 이슈·PR 상세에서 확인할 수 있습니다.

이슈가 닫히면 몬스터가 사라지고, 다시 열리면 부활 효과가 나타납니다. PR은 머지되거나 닫히면 작업 이력으로 이동하고 다시 열면 지도에 돌아옵니다. PR 머지와 이슈 종료는 각각의 GitHub 상태를 따릅니다.

## 브랜치 도로망

도로는 PR의 작업 브랜치와 대상 브랜치를 연결합니다. 다리는 왕궁과 광장을 잇는 지도 요소이며, 실제 브랜치 관계는 확인된 PR 기록으로 읽습니다. 연결할 대상이 지도에 없으면 개발 광장 또는 왕궁에서 점선 안내로를 표시합니다. 점선 안내로는 브랜치 생성 출처를 뜻하지 않습니다. 지도에는 열린 PR과 연결된 경로를 우선해 최대 여섯 개를 표시합니다. 작은 분기점에서 갈라지는 곡선을 따라 PR 시설과 연결된 이슈를 찾을 수 있습니다. 여러 PR이 여러 이슈와 연결된 경우 기본 지도에서는 순서가 교차하는 이슈 연결을 생략합니다. 이슈나 PR을 가리키거나 선택하면 해당 연결을 확인할 수 있습니다. 분기점을 선택하면 브랜치 이름과 PR을 볼 수 있고, 추가로 확인한 브랜치는 목록에서 볼 수 있습니다.

같은 부모에서 갈라진 브랜치는 직접 연결된 열린 PR 중 가장 작은 번호가 왼쪽에 오고, 열린 PR이 없는 브랜치는 그 뒤에 놓입니다. 같은 브랜치의 PR도 번호순으로 표시합니다. 이슈가 여러 PR에 연결되면 가장 왼쪽 시설을 따릅니다. 같은 시설에 연결된 이슈끼리는 번호순이며, 연결된 열린 PR이 없는 이슈는 그 뒤에 번호순으로 놓입니다. 하위 이슈는 부모 아래에서 형제끼리 같은 규칙을 따릅니다. 두 표시 모드에서 배치 규칙은 같고, 경고와 활동 상태는 순서를 바꾸지 않습니다.

건물 외형과 네 유산의 집계 대상은 [SVG 도감](assets.md)에서 확인하세요.

## 표시 모드

상단의 지도 아이콘은 **월드 모드**, 연결된 노드 아이콘은 **간단 모드**입니다. 간단 모드에서는 왕궁·광장·PR을 사각형, 이슈를 원형, 상위 이슈를 육각형으로 표시합니다. 유산 막대 높이와 이슈 크기에는 월드 모드와 같은 성장 기준을 적용합니다. 두 모드 모두 PR과 이슈에 마우스를 올리면 `PR #번호 · 원래 제목` 또는 `이슈 #번호 · 원래 제목`이 표시됩니다. 유산 건물의 이름도 툴팁에서 확인할 수 있습니다. 터치 화면에서는 건물을 눌러 상세 정보를 엽니다. CX는 Codex, CL은 Claude입니다. 굵은 테두리는 활동 중인 작업, 느낌표는 확인이 필요한 작업을 표시합니다.

오른쪽 아래 범례에는 간단 모드에서 GitHub, Codex, Claude가 표시됩니다. 세 원형 배지는 테두리를 포함한 바깥지름이 같고, 항목명은 모두 같은 글자색을 사용합니다. 월드 모드에서는 GitHub가 파티장으로 표시됩니다. 게시된 릴리스와 태그는 두 모드 모두 왕궁의 배포 기록에서 확인할 수 있습니다.

두 아이콘과 그 사이 여백은 하나의 토글 버튼입니다. 강조된 아이콘이 현재 모드이며, 버튼의 어느 곳을 누르든 반대 모드로 전환됩니다. 키보드에서는 Tab으로 버튼에 포커스를 옮긴 뒤 Enter 또는 Space로 전환할 수 있습니다.

모드를 전환해도 지도 위치, 선택과 갱신 주기를 유지합니다. 처음 방문하면 월드 모드로 열리고, 이후에는 이 브라우저에서 마지막으로 선택한 모드로 열립니다.
