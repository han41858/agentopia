# Agentopia

Agentopia는 GitHub 저장소를 RPG 월드맵으로 보여주는 읽기 전용 웹앱입니다. 저장소마다 왕국이 생기고, 성벽 밖에는 열린 이슈가 몬스터로, 안에는 열린 PR이 시설로 나타납니다. 몬스터나 시설을 선택하면 누가 작업 중인지, 어떤 GitHub 기록이 연결되어 있는지 볼 수 있습니다.

이슈 팝업에서는 실패·개입 사유와 근거를 확인할 수 있습니다. 연결된 GitHub Actions 실행은 팝업을 열면 바로 표시되며, 목록을 스크롤해 시작 시각(KST), 상태, 실행 이름과 GitHub 링크를 확인할 수 있습니다.

## 시작하기

Node.js 24와 npm으로 실행한 뒤 터미널에 표시된 주소를 엽니다.

```bash
npm ci
npm run dev
```

처음에는 Agentopia 왕국이 보입니다. 상단 **+** 버튼에 저장소 주소나 `owner/repo`를 입력해 왕국을 추가하세요. 계정 이름만 입력하면 여러 저장소를 골라 추가할 수 있습니다. 공개 저장소는 바로 볼 수 있고, 비공개 저장소는 티켓 버튼에서 GitHub 토큰을 연결하면 됩니다.
